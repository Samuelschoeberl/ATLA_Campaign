## Mushroom colours

You can optionally declare per-mushroom colour mappings here. Each mapping is a simple
line of the form:

```
<path>=#rrggbb
```

Notes:

- Use the same path ids that the visualiser uses (directory ids end with '/').
- Example entries:

```
Anju/ = #3ed7e4ff
Ash/  = #1d2088ff
Anju/ = #3e9f51ff   # alternate shorter path form
```
