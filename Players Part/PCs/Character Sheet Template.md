## Per-element modular sections

Only keep the sections below for elements the character actually has levels in. If the character is a single-element bender (e.g. Water), delete the other sections. `update_char.py` will also add/remove these sections automatically when run with pcs_input data.

### How to use these modules

- If an element's level (in the `## Bending Levels` table or in `pcs_input.md`) is 0, remove the corresponding `## <Element>Bending` section.
- If the element has levels, keep the section and fill in moves, slots, or notes for that element.
- The script looks for headers like `## Airbending`, `## Waterbending` etc. Keep that exact spelling for automatic syncing.
