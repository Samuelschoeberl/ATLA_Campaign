## 🚀 How to Set Up

1. **Clone or Download the Repository**
    
    `git clone <repo-url>`
    
    Or download as ZIP and extract.
    
2. **Open as an Obsidian Vault**
    
    - Start **Obsidian**.
        
    - Select **"Open folder as vault"**.
        
    - Navigate to the downloaded repository and open it.
        

👉 This gives you the best file explorer experience and lets you use all notes, links, and structures directly.

# Git Plugin

### Step 1 — Install Git

Download and install Git: [https://git-scm.com/downloads](https://git-scm.com/downloads)

---

### Step 2 — Generate a Personal Access Token

In GitHub (requires an account):

- Go to **Settings → Developer settings → Personal access tokens → Tokens (classic)**.
    
- Click **“Generate new token”**.
    
- Set:
    
    - **Scopes:** Select `repo`.
        
    - **Expiration:** Choose **no expiration** (recommended for backups).
        

---

### Step 3 — Install the Obsidian Git Plugin

In **Obsidian**:

- Go to **Settings → Community plugins**.
    
- Enable community plugins.
    
- Search for **“Obsidian Git”** and install it.
    
- Restart Obsidian.
